# What To Do Next

Use this as the first real SprintOS loop. Do not add more SprintOS features before you complete it once.

## First Real Workflow

1. Open SprintOS.
2. Run Setup Doctor.
3. Create a local backup.
4. Run Guided Demo once.
5. Quick Launch one real idea.
6. Follow the Project Command Center.
7. Export the workspace.
8. Open the workspace in Codex.
9. Sync the workspace back into SprintOS.
10. Run Run & Verify.
11. Create a Release Pack.
12. Add tester feedback.
13. Generate the next Codex prompt.

## Rules

- Do not build more SprintOS features until you complete one real idea loop.
- Record friction points as they happen.
- Only fix friction that blocks use or meaningfully slows the loop.
- Do not treat "this could be nicer" as enough reason for more SprintOS surface area.

## What To Watch

Record whether the friction was about:

- choosing the next step
- getting to a testable prototype
- handing work to Codex
- syncing work back into SprintOS
- verifying the result
- packaging something a tester can actually use

## Success Condition

SprintOS is proving itself if one real idea can move through this loop without needing a new major product feature.
